📖 How to play

  1. Create a new game (you get a UUID) or join an existing one using its UUID.
  2. Set your secret 4‑letter word. Keep it hidden!
  3. Wait for both players to set words – the game starts automatically.
  4. On your turn, guess the opponent's word (4 letters).
  5. You get a number = how many letters match (any position).
  6. First to guess 4 (all letters match) wins!
